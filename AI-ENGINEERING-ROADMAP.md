# AI Engineering Portfolio Roadmap

**Focus:** applied machine learning, trustworthy LLM systems, local inference, evaluation and production APIs.

## Current foundations
- [VidExtract](https://github.com/idginity124/VidExtract): local speech recognition, transcription, translation and desktop integration.
- Existing software projects demonstrate product delivery, API design and cross-platform applications.
- Prior computer-vision studies include bird/airplane detection and NER experiments. Separate code/metrics will be linked only after publication.

### Definition of done
A project is portfolio-ready when it has **reviewable source code, reproducible setup, tests, a documented dataset license, honest measured results, limitations, and screenshots or a real demo**. Upcoming work is explicitly labeled *planned* or *in development*, not finished.

### Near-term milestones
1. Publish DeskMind, EvalForge and TicketSense in independent repositories.
2. Replace synthetic demo data with an appropriately licensed benchmark where possible.
3. Run CI on GitHub Actions and document real accuracy, latency and failure cases.
4. Connect the strongest new repositories to the profile README and pin the best six.
